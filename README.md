Hoje assisti ao vídeo do canal o curso de html e css, o começou “Parágrafos e Quebras”, Parágrafos, o professor explicou que apertar Enter ou colocar o vários espaços no código HTML que não muda a forma como o texto aparece na página. O navegador junta tudo que um único parágrafo. Para criar outro parágrafo, é preciso usar a tag. Quebras de linha, o explicou, o texto passe para a linha de baixo sem criar um novo parágrafo, usamos a tag. Essa tag faz apenas uma quebra de linha e não precisa de uma tag de fechamento. Linguagem de marcação, o professor explicou o são as tags que organizam e definem a estrutura da página por isso, é importante o usar as tags corretas e não se preocupar em deixar o código com a aparência do resultado final…
